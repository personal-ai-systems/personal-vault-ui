Personal Vault — quick QA

Version 0.2.1-preview.5 · Mac with Apple Silicon (M1/M2/M3 or later)

Allow about 10–15 minutes. Your existing Vault is a separate folder. Updating the app must keep that folder and your saved memories.

What changed

  • A simpler English interface: Recent, Memory and Files, with Archive and Recently Deleted kept separate.
  • Connect Codex from the app menu. Connected clients receive the actual saved text rather than an empty acknowledgement.
  • Long-source lookup keeps the passages it used to omit; original files and their languages stay unchanged.
  • Updated runtime dependencies and Electron. The connection remains local to your Mac and requires its private app token.

Update the installed app

  1. Save open memories, stop any Codex work using this Vault, and quit Personal Vault.
  2. Unzip the QA download in Finder. Drag Personal Vault.app into Applications. Choose Replace. Do not delete the old app first, choose Keep Both, run an app cleaner, or remove your Vault/Library settings.
  3. Open Personal Vault from Applications. In the top macOS menu choose Personal Vault → About Personal Vault. Check the version is 0.2.1-preview.5.
  4. Check the selected folder path and open an existing memory. If it asks for a folder, use Open an existing folder and select your original Vault. Do not import or duplicate it just to upgrade.

If macOS blocks the preview: this test build is not Apple-notarized. After a launch attempt, the supported option may appear in System Settings → Privacy & Security → Open Anyway. Use it only for the trusted download. Do not disable Mac security or remove quarantine. If no safe approval is available, stop and send the exact message.

What this preview does not promise

  • Connecting local Codex does not automatically connect ChatGPT on the web or archive every chat.
  • A new Vault is not automatically given a model-reviewed memory summary or a background context index by this desktop build. Ordinary file search/read works; broad questions can still miss the right context.
  • This is a manual preview update, not an automatic updater or an Apple-notarized release.
