# Personal Vault 0.2.1-preview.3

An early Apple Silicon Mac preview. Your notes remain ordinary Markdown files in the folder you choose.

## Fixed

- Recent no longer crashes when a note's optional title is an object, list or number; it uses the filename instead. Search uses the same readable fallback.
- Opening a note with malformed metadata from the folder browser now shows a short warning and the complete original text, matching Recent's preview. The file is not rewritten.

This build also includes the previously source-only fixes for malformed metadata and the native macOS About panel. Russian, emoji and punctuation are supported; no conversion to another encoding is needed. Newest-first ordering, normal editing, attachments and archive/restore remain included.

## Try it

Download the DMG or ZIP from this release, quit the old app and replace it in Applications. Check **Personal Vault → About Personal Vault → 0.2.1-preview.3** before testing. Use a separate test folder first. Follow the [first-time testing guide](https://github.com/personal-ai-systems/personal-vault-ui/blob/v0.2.1-preview.3/docs/testing-preview.md).

## Limits

- Apple Silicon macOS installer only; this is not an Intel/Windows/Linux installer.
- Ad-hoc signed, not Developer ID signed or notarized. macOS may require a new explicit Open Anyway approval. Do not disable macOS security globally.
- Import converts conversation text; referenced export attachments are not copied.
- ChatGPT is not connected automatically. Imported files can be supplied individually; automatic search requires a separate MCP connection. The desktop's local endpoint is not a remote/mobile service.
- No built-in internet sharing, cloud sync, automatic updater or guaranteed unsaved-draft protection.
- Local automated checks do not establish acceptance on a second Mac or in another user's ChatGPT account.

See `SHA256SUMS.txt` in the release for archive checksums.
